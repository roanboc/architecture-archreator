Para principiantes totales

¿Nunca has usado GitHub? Empieza desde cero.

No necesitas ser desarrollador, y no necesitas instalar nada — ni VS Code, ni terminal. Necesitas tres cosas gratuitas y unos quince minutos. Esta página te lleva de la nada a tu primer cambio revisado, empezando por el camino más barato.

La pregunta que todo el mundo hace

"¿Necesito VS Code?" No. VS Code es una opción entre muchas, no un requisito. Todo lo que sigue ocurre en un navegador web: tu código vive en un sitio web (GitHub), y tu "editor" es un cuadro de chat donde escribes peticiones. Existe un camino sin instalar nada, y también uno genuinamente gratuito.

Todo el asunto, en tres piezas

Antes de los pasos, el panorama. Construir así requiere exactamente tres cosas — y una persona (tú) sigue al mando de las tres.

1 · GitHub

Un sitio web gratuito que guarda tu proyecto y recuerda cada cambio. Piensa en "Google Docs para código" — tu trabajo vive aquí, en la nube, no en tu portátil. Crear una cuenta es gratis y no pide tarjeta.

2 · Tu copia de archreator

Un clic en Use this template te da tu propia copia privada — el esqueleto de arquitectura, los skills, las plantillas de revisión — con su propio historial limpio. Esa es la vía de abajo, y la más sencilla si empiezas de cero.

¿Ya tienes un proyecto? Instálalo como plugin: /plugin marketplace add roanboc/archreator. Los mismos skills, y /plugin update los mantiene al día.

3 · Un agente de IA

Lo que de verdad construye. Describes lo que quieres en lenguaje corriente; él hace el trabajo y te entrega un cambio para aprobar. Corre en la nube o en tu navegador — nunca tocas un editor de código a menos que quieras.

Ese es el ciclo Solicitante → Agente → Revisor alrededor del cual está construido todo este proyecto: tú pides y apruebas, la IA construye en medio. Nada se publica hasta que tú dices que sí.

Prepáralo: tres pasos

1

Crea una cuenta gratuita de GitHub

Ve a github.com/signup y regístrate con un correo. Es gratis, sin tarjeta de crédito. Esta es la cuenta que será dueña de tu proyecto.

2

Haz tu propia copia

Abre la plantilla archreator y pulsa Use this template → Create a new repository. Dale un nombre, déjalo Privado, pulsa Create. Ya tienes tu propia copia — el inicio rápido del README (en inglés) tiene los mismos pasos con imágenes.

3

Apunta un agente de IA hacia ella

Elige uno de los agentes de abajo y conéctalo al repositorio que acabas de crear. Eso es toda la preparación — a partir de aquí solo describes cambios y revisas lo que vuelve.

El paso 3, ampliado: ¿qué agente de IA?

Hay muchos; aquí tienes los dos puntos de partida más fáciles, primero el más barato. Ambos corren en tu navegador — ninguno necesita VS Code ni instalación alguna. Los precios cambian, así que cada uno enlaza su propia página de planes; las cifras de aquí son las vigentes en el momento de escribir esto (mediados de 2026).

Gratis, sin tarjeta — GitHub Copilot

La IA propia de GitHub tiene un nivel gratuito (aproximadamente 2.000 autocompletados de código y 50 peticiones "premium"/de agente al mes) que funciona directamente dentro de github.com y su editor en el navegador — nada que instalar. Ideal para probar el ciclo sin gastar un céntimo.

La pega: el agente totalmente autónomo de "asigna una tarea, recibe un cambio terminado" requiere un plan de pago de Copilot; el nivel gratuito te da un agente que tú diriges, limitado a un número pequeño de peticiones al mes.

Lo más sencillo de principio a fin — Claude Code en la web

Ve a claude.ai/code, conecta tu repositorio de GitHub y escribe lo que quieres. Trabaja en un entorno aislado en la nube y abre un cambio para que tú lo revises y fusiones — exactamente el ciclo Solicitante → Agente → Revisor, con cero preparación en tu máquina. Es lo más parecido a cómo está pensado que funcione archreator.

La pega: no hay nivel gratuito de Claude Code. La entrada más barata es un plan Pro de Claude (unos 20 $ al mes, que incluye Claude Code en la web), o uso de API de pago por consumo, que puede salir muy barato si solo construyes de vez en cuando.

¿Eres estudiante o mantienes un proyecto de código abierto? Puede que las herramientas de pago te salgan gratis.

El GitHub Student Developer Pack da a estudiantes y docentes verificados Copilot Pro (y otras herramientas) sin coste, y Anthropic tiene un programa de acceso gratuito para quienes mantienen proyectos populares de código abierto. Merece la pena comprobarlo antes de pagar por nada.

Nuestra recomendación para el arranque gratuito más sencillo: crea la cuenta y el repositorio (pasos 1–2), prueba el nivel gratuito de GitHub Copilot en el navegador para sentir el ciclo, y pásate a Claude Code en la web cuando quieras un agente que tome una petición completa y te devuelva un cambio revisado de principio a fin.

¿Quieres un paso a paso para una herramienta concreta?

Esta página se mantiene agnóstica de herramienta a propósito, para que no tengas que elegir proveedor antes de entender la forma. Hay guías dedicadas, clic a clic, para agentes concretos (Claude Code, GitHub Copilot y otros) planificadas como páginas futuras — hasta que lleguen, la comparación de arriba más la documentación enlazada de cada herramienta te llevarán hasta el final. Si te atascas, la guía CONTRIBUTING (en inglés) es la versión completa y canónica del proceso.
