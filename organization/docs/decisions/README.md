# Decisions — the organization behind archreator

_[← Project README](../../README.md) · [EA home](../ea/README.md)_

Consequential calls about **this organization** that are smaller than an
initiative but too significant to leave buried in a pull-request thread.
Written with the `decision-record` skill, numbered chronologically.

Decisions about **the method** live in
[`meta/decisions/`](../../../meta/decisions/README.md) instead. The split is
the same one [layer 4](../ea/4_application/2_application-components.md#how-this-layer-relates-to-meta-and-site)
draws: this tree decides what the organization does; `meta/` decides how the
method is built.

A decision record supplements a scope document, never replaces it: if the
call also changed EA elements, the scope document in
[`docs/scope/`](../scope/README.md) is the primary record and the decision
explains *why* one row reads the way it does.
