Architecture-first, for a world where AI is one of the actors

archreator is a GitHub template for small enterprises and solutions: strategy and business architecture get validated before any code, and an AI system can hold a real business role — with a stated autonomy level and decision rights — alongside the people it works with.

Read the guide → See it applied → Use the template →

The one rule

A change in requirements is never coded directly. It is aligned top-down through five ArchiMate layers — strategy, business, information, application, technology — recorded in a scope document, and only then implemented. Every architecture element names the code that realizes it, or is marked Pending, so the documentation stays checkable against the repository at any time.

What makes this site itself an example

This site is not a mockup — it is the deliverable of a real initiative (example/docs/scope/1_publish-guidance-site.md) built by following that exact process. One of its business actors, Docs Agent, is an AI: it drafts guidance content and opens pull requests, at a co-pilot autonomy level, reviewed and merged by a human maintainer before anything here goes live. The guide explains the notation; the architecture page shows it modeled for this project specifically.

This page summarizes the method — it doesn't restate it as a second authority. The canonical process lives in CONTRIBUTING.md and .claude/skills/ in the template repository.
