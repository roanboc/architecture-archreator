# Strategy layer — archreator

_[← EA home](../README.md)_

**ArchiMate viewpoints:** Motivation, Strategy.

At [Depth 1](../README.md) this layer stays light: who cares about
archreator, what pressures it, what it is trying to achieve, and the
principles that gate every change to the method. There is no capability or
value-stream document — archreator is a method, not an operating business,
and inventing a capability map for it would be modeling for its own sake,
which is the failure this project exists to avoid.
