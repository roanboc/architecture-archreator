# Roadmap

_[← EA home](../README.md) · [Scope documents](../scope/README.md)_

**ArchiMate viewpoint:** Implementation & Migration (Plateau, Gap).

**Not started.** The site has no target state of its own. It realizes a service
of the product it is nested under, and where it is going is decided on
[the product's roadmap](../../../architecture/6_transition/README.md) — a
plateau that changed the site without changing the method would be a plateau in
the wrong tree.

The folder stays rather than being deleted, because an empty folder that says
why is a known gap and a missing one is an unknown gap.

**What would change the answer.** The day the site acquires a direction the
method does not imply — an audience, a publishing cadence or a shape decided
for the site rather than derived from the product — it earns a roadmap here,
through the `plan-the-transition` skill and approved at **Gate 1**.
