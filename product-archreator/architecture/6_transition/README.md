# Where the product is going

_[← Front door](../README.md) · [Scope notes](../scope/README.md)_

The one folder in the model that describes a future. Every numbered layer
describes today; each scope note describes one change already made. This
folder says which features come next, what is missing for each, and in what
order.

| # | Document | Holds |
| - | -------- | ----- |
| 1 | [Features](./1_target-state.md) | The three features, each written as the state the product reaches, and what is missing to get there |
| 2 | [Order](./2_sequence.md) | The order the work happens in, and what each step needs first |

A feature and a missing piece each carry one of three words: **Planned**,
**In progress** or **Done**. Nothing here is deleted when it is done or
dropped; the word changes and the row stays, so a reader can see what was
intended and what became of it.
