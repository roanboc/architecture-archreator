# Decisions

_[← EA home](../README.md)_

Calls that are **architecture-significant but smaller than an initiative** —
each one a numbered record explaining *why*, while the layer document it
touches carries the *what*.

A decision record is a historical document once accepted: its words do not
change. A call that is later reversed gets a new record, and the old one's
`Status` line points at it.
