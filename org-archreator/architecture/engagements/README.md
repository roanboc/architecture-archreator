# Engagements

_[← EA home](../README.md)_

**Not architecture.** What applying the method to a real engagement or
initiative taught — what the method did not tell you to do, and what you did
instead — generalized past recognition of any client. No elements are defined
here, and no identifier is assigned.

This folder is the mechanism behind
[`CAP2.3`](../1_strategy/2_capabilities-and-resources.md), and stage 1 of
[decision 1](../decisions/1_take-coa1-staged.md): a pattern that recurs across
notes becomes method, in the `archreator` repository, where anyone gets it.

**A single note is not evidence.** The rule the `run-retrospective` skill sets
is to wait for a second occurrence before changing the method, because one
case is indistinguishable from a preference.
