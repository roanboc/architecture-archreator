# Domains

_[← EA home](../README.md)_

**Not used yet.** This tree is
[Depth 2 — Organization](../README.md#modeling-depth): one organization sharing
one strategy — a single capability base, a single portfolio, and a single
person who says yes. There is no business line whose customers, economics and
approver differ enough from the rest to justify splitting the model.

The folder stays rather than being deleted, because an empty folder that says
why is a known gap and a missing one is an unknown gap.

**What would change the answer.** A domain is a part of the organization
modeled as though it were an organization in its own right. The day something
the organization builds acquires customers, economics and an approver distinct
from the rest of it, the model splits — an ordinary initiative, not a restart.
The `model-domains` skill holds the full test and the charter format; they are
not restated here, because a copy of a rule is a rule that drifts.
