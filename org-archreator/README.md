# org-archreator

The architecture model of **the organization that publishes archreator**: who
it serves, what it must be able to do, what it has to work with, and which
courses of action it has taken.

What the organization builds is modeled separately —
[`product-archreator/`](../product-archreator/architecture/README.md) for the
method itself.

| Read | For |
| ---- | --- |
| [`architecture/README.md`](./architecture/README.md) | The notation — glyphs, shapes, layer colours |
| [`architecture/0_business-design/`](./architecture/0_business-design/README.md) | The value proposition and business model canvases the strategy is derived from |
| [`architecture/1_strategy/`](./architecture/1_strategy/README.md) | Stakeholders, drivers, goals, capabilities, resources, courses of action |
| [`architecture/scope/`](./architecture/scope/README.md) | One document per initiative, with its gate approvals |

**Modeling depth: 2 — Organization.** Contribution rules are in the
[root `CONTRIBUTING.md`](../CONTRIBUTING.md).
